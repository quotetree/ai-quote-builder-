# Screenshots for Landing Page

This directory contains screenshots for the User Journey section of the landing page.

## Required Screenshots

Please add the following screenshot files:

1. `new-project.png` - Screenshot of the "Create New Project" interface
2. `scope-chat.png` - Screenshot of the chat interface where users describe their scope
3. `chat-results.png` - Screenshot showing the AI-generated product suggestions
4. `products-markup.png` - Screenshot of the product selection and markup interface
5. `quote-log.png` - Screenshot of the quote log/management view
6. `quote-pdf.png` - Screenshot of a generated PDF quote

## Format Requirements

- Format: PNG
- Recommended width: 1920px or higher
- Make sure screenshots show the actual application interface cleanly

The landing page will display these screenshots in a browser frame mockup.
